# BOM-Diff
A standalone tool to compare changes to a bill of materials.

- Pick files in csv, excel, or ODF formats.
- Specify the columns representing the part number, description, and quantity.
- Pick an output format and location, and compare the results!

# Features
- [x] Select two BOMS and output result
- [ ] Select columns by name when headers exist
- [ ] Select columns by number when headers don't exist
- [ ] Select description as ID as option
